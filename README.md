# Meta Ads Performance Dashboard — Facebook & Instagram

## Project Overview

This project presents a Meta Ads Performance Dashboard built using Microsoft Power BI to analyze digital advertising performance across Facebook and Instagram.

The dashboard brings important advertising KPIs, engagement trends, campaign information, and audience analysis into one interactive report.

## Key Performance Indicators

The dashboard includes the following metrics:

- Impressions
- Clicks
- Shares
- Comments
- Purchases
- Engagements
- Click-Through Rate (CTR)
- Engagement Rate
- Conversion Rate
- Purchase Rate
- Total Advertising Budget
- Average Budget per Campaign

## Dashboard Features

- KPI cards for advertising performance
- Engagement analysis by age and gender
- Country-level engagement visualization
- Weekly and hourly engagement trends
- Monthly analysis using a calendar view
- Performance comparison by ad type
- Campaign selection and dynamic measure filters
- Facebook and Instagram dashboard pages

## Tools Used

- Microsoft Power BI
- Power Query, if used for data preparation
- DAX, if used for measures and calculations
- Data visualization and dashboard design

## Project Objectives

1. Monitor key digital advertising performance indicators.
2. Understand audience engagement patterns.
3. Compare advertising performance across different ad types.
4. Explore engagement trends over time and across countries.
5. Present advertising data in a clear, visual format.

## Key Learning Outcomes

- Designing a multi-page Power BI dashboard
- Presenting KPIs using cards and charts
- Exploring audience and campaign performance
- Organizing marketing metrics for business analysis
